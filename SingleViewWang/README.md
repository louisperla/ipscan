# Single View Wang

This directory contains a placeholder Xcode project demonstrating how to set up a nib-based single view app as described in Neuburg Text Book #1 Chapter 8.

Due to environment limitations this project is not generated by Xcode, but it contains the Swift source files and a `.xib` file. To use it, create a new Xcode project named `Single View Wang` and replace its files with the ones in this folder.
